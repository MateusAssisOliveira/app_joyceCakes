# Firebase Legacy Archive

Esta pasta guarda documentos historicos anteriores a migracao para Supabase + Vercel.

Eles nao representam a arquitetura ativa do projeto e nao devem ser usados como guia de instalacao, seguranca ou deploy atual.

Para a arquitetura vigente, use os documentos em `docs/`, `docs/supabase/` e o `README.md` da raiz.
